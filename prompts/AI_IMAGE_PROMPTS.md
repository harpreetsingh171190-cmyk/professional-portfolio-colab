# AI illustration prompts

Use these prompts in an image generator. Keep the resulting artwork separate from measured charts and code screenshots.

## 1. GitHub repository banner (16:9)
Create a polished 16:9 technical illustration for a Big Data and Machine Learning portfolio. Show a distributed data pipeline flowing from log files and CSV datasets through Apache Spark processing, data validation, a machine-learning model, and a dashboard. Modern minimal editorial style, deep navy and teal accents, clean lighting, balanced negative space, crisp geometric icons, no logos, no watermarks, no fake statistics, no tiny unreadable text. Leave the left third relatively uncluttered for a title to be added later in an editor.

## 2. Cloud architecture illustration (16:9)
Create a clean technical architecture illustration, 16:9 landscape. Depict data sources, an ingestion layer, distributed processing with Apache Spark, a storage layer, a model-training stage, and a visualization dashboard. Use distinct boxes and directional arrows, consistent line weight, accessible contrast, simple vector-like shapes, no company branding, no invented metrics, no watermarks. Do not attempt long labels; leave room for labels to be added manually.

## 3. Vertical project promo (9:16)
Create a 9:16 vertical promotional illustration for a student Big Data project. Visual theme: data streams transforming into structured tables, distributed compute nodes, and a simple chart dashboard. Professional, clean, high contrast, no text, no logos, no watermark, no fake numbers. Keep the central subject clear with space at the top and bottom for captions.

## Accuracy tip
Image models often misspell technical labels. For a precise architecture, build the boxes and arrows in Mermaid or draw.io, then use AI artwork only as a decorative background. Never present AI-generated charts as actual experimental results.
