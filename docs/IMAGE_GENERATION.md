# How to generate project images

There are two different meanings of "images":

## A. Data visualization images (recommended for this project)
These are charts based on data and model output. They are generated by code, not painted by an AI.

1. Install dependencies using the commands in the main README.
2. Generate the sample CSV:
   `python -m src.generate_data`
3. Generate the analysis charts:
   `python -m src.visualize --input data/power_plant.csv --output-dir outputs/charts`
4. Train the model and generate the actual-vs-predicted plot:
   `python -m src.ml_pipeline --input data/power_plant.csv --output-dir outputs/ml`
5. Find the PNG files in `outputs/charts/` and `outputs/ml/`.

Charts are reproducible because the sample data generator uses a fixed random seed. Replace the sample CSV with a verified real dataset only after checking its license, schema, missing values, and provenance.

## B. AI-generated illustrations
For a project banner, architecture illustration, or thumbnail, write a prompt that specifies:
- subject (e.g. distributed data-processing architecture)
- layout and aspect ratio (e.g. 16:9)
- visual style (e.g. clean technical infographic)
- labels that must be included
- explicit instruction not to fabricate charts or statistics

For accurate technical diagrams, create the diagram in Mermaid, draw.io, or another editable diagram tool rather than relying on an image model to spell labels correctly. Keep illustrations separate from measured charts.
