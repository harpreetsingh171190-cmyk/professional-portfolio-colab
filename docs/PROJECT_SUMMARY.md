# Project summary

## Demonstrations
1. Reproducible synthetic data generation.
2. PySpark distributed word count.
3. Access-log aggregation and malformed-row handling.
4. Regression training and held-out evaluation.
5. PNG chart generation.

## Limitations
The included power-plant-like dataset is synthetic, metrics depend on this generated sample, and the regression model is a demonstration rather than a production system. Local Spark requires a compatible Java runtime. Cloud environments may need provider-specific configuration.
